# 📜 Algorithm Complexity Analysis ($\LaTeX$)

A collection of rigorous mathematical proofs and runtime analyses regarding Asymptotic Computational Complexity. This project demonstrates technical documentation skills using **$\LaTeX$** to typeset limits, series summations, and formal logic.

## 🧮 Topics Covered

The document explores fundamental concepts in algorithm analysis:

* **Asymptotic Notation:** Formal proofs for Big-Theta ($\Theta$), Big-Omega ($\Omega$), and Little-Omega ($\omega$) relationships.
* **Limit Theory:** Applying **L'Hôpital's rule** to determine dominance between super-logarithmic functions (e.g., $2^{\sqrt{\log n}}$ vs $n$).
* **Function Properties:** Disproving assumptions about monotonic functions in complexity theory using counter-examples.
* **Code Runtime Analysis:** Calculating the time complexity ($\Theta$) of nested loops using summation series techniques ($\sum$).

## 📝 Technical Highlights

This repository serves as a sample of technical typesetting capabilities:

* **Complex Math Typesetting:** Implementation of limits, fractions, square roots, and cases environments.
* **Structure:** Usage of `enumerate` and `section` for logical document flow.
* **Custom Commands:** Definition of macros (e.g., `\dlim`) for cleaner code.

## 🚀 Usage

To compile the source code into a PDF, you need a $\TeX$ distribution (like TeX Live or MiKTeX).

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/NadavMenirav/Algorithm-Complexity-Analysis-LaTeX.git](https://github.com/NadavMenirav/Algorithm-Complexity-Analysis-LaTeX.git)
    ```
2.  **Compile:**
    ```bash
    pdflatex ex1.tex
    ```
